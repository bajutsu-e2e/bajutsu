# Bajutsu documentation

This directory is the source for the Bajutsu documentation site. The published, browseable version
lives at **<https://bajutsu-e2e.github.io/bajutsu/>** and adds search, navigation, and an
English/日本語 switch.

To read the source here on GitHub, start with [overview.md](overview.md), the per-feature reference
in suggested reading order, or jump straight to the [Getting started tutorial](getting-started/index.md).
To *contribute*, not just run Bajutsu, follow the
[Contributor workflow tutorial](contributor-workflow-tutorial.md), which walks through your first
proposal and first implementation end to end. The [glossary](glossary.md) defines the domain vocabulary term by
term. The generated Python API reference is under [`api/`](api/index.md).

> This page is the GitHub folder index; it is excluded from the built site (see `exclude_docs` in
> [`mkdocs.yml`](../mkdocs.yml)). The site's landing page is [`index.md`](index.md).
