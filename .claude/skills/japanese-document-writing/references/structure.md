# 文書の構成と手順の書き方

文書全体の構成と手順の書き方について、言語に依存しない規範は上位規範
[`document-writing`](../../../../.apm/skills/document-writing/references/structure.md) の `references/structure.md`
に置いてある。タイトルと冒頭、見出しの並べ方、手順の一歩を組み立てる5つの単位（目的、操作、入力、確認、
補足）、用語の関係、本筋と追加の情報の分け方、見た目の区切りと意味の区切りを扱う。以下は、その規範を
日本語の文書に当てはめるときの補足である。

- [`expression.md`](expression.md#冗長の排除) は「読者が自力で補える中間段階の説明は書かない」と求める。
  ここで省くのは推論の中間段階であり、操作と入力、成功の条件は省かない。読み手が補えるものとしては
  扱わない。
- 手順書の見出しは作業の順に並べ、作業の対象を含めて節を特定する。[`formatting.md`](formatting.md#見出しの付け方)
  は「例に戻す」のような作業の手順だけを述べる見出しを退ける。手順書の節見出しに限っては、この規範を
  優先して「Chromium を導入する」「ログインできたかを確かめる」のように書く。「準備」「実行」のような
  情報量のない見出しは引き続き使わない。
- 手順の5つの単位を箇条書きで示すときは、[`formatting.md`](formatting.md#整形) の形に従い、
  「**目的**：この節で何をするのか」のように全角コロンで書く。
